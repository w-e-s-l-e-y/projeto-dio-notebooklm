# 🚀 Guia Estratégico do NotebookLM: Aprendizagem Acelerada

> Este repositório contém a documentação e os prompts estruturados para o projeto final da disciplina **"Acelere sua aprendizagem com IA: Explore o poder do NotebookLM"** pela DIO. O objetivo é demonstrar como transformar o NotebookLM em um assistente de pesquisa de alta performance, utilizando o rigor analítico de especialistas para dissecar a própria ferramenta.

---

## 📑 Sobre o Projeto

O projeto consiste em um NotebookLM configurado para atuar como um guia mestre sobre si mesmo. A grande inovação aqui foi aplicar a lógica de especialistas em concursos públicos (foco em detalhes, diferenciação técnica e mapeamento de falhas) para organizar o aprendizado da plataforma.

🔗 **[Acesse o Notebook do Projeto Aqui](https://notebooklm.google.com/notebook/afc27d5d-434f-4b2a-92e5-f88c9c6434ee)**

---

## 🛠️ Tecnologias e Metodologias

*   **NotebookLM**: IA baseada em fontes (Source-grounding).
*   **Engenharia de Prompt**: Criação de diretrizes de comportamento e saídas estruturadas.
*   **Aprendizagem Ativa**: Metodologia de estudo focada em sintetizar e extrair o "coração" do conteúdo (80/20).

---

## � Prompts Desenvolvidos

Neste projeto, foram criados três prompts principais que moldam a experiência do usuário dentro do notebook:

### 1. Prompt de Personalização (O Especialista)
Define o comportamento da IA para atuar como um Master Expert em NotebookLM, focando em:
*   🎯 **Recurso de Elite**: O que gera mais resultado.
*   ⚠️ **Ponto de Falha**: Onde o usuário costuma errar.
*   ⚖️ **Distinções Técnicas**: Diferenças entre recursos similares.

### 2. Prompt de Geração de Infográficos
Instrução para que a IA organize visualmente o conteúdo, criando estruturas de:
*   Título central e blocos temáticos.
*   Quadros de "Atenção" para exceções.
*   Hierarquia de conceitos para facilitar a memorização.

### 3. Nota de Comportamento para Pesquisa
Configuração para que a IA trate a documentação como "Lei Seca" (verdade absoluta), garantindo que todas as respostas tenham citações diretas e embasamento técnico inquestionável.
